# Сборки Springland

Страница выдачи приложения водителям: https://springland-dev-team.github.io/springland-releases/

APK лежит здесь только в зашифрованном виде (`app.bin`, AES-256-GCM). Скачать его можно со страницы по индивидуальному коду доступа: страница расшифровывает файл прямо в браузере телефона. Коды в репозитории не хранятся, в `keys.json` для каждого кода лежит только зашифрованный им ключ.

Выдачей и отзывом кодов занимается ведущий разработчик.
