# Сборки Springland

Страница выдачи приложения водителям: https://springland-dev-team.github.io/springland-releases/

APK лежит здесь только в зашифрованном виде (`app.bin`, AES-256-GCM). Чтобы скачать его, на странице вводится индивидуальный код доступа. Код проверяет сервер на Cloudflare Workers: он ведёт журнал скачиваний, гасит одноразовые и просроченные коды и при успехе отдаёт странице ключ. Страница расшифровывает файл прямо в браузере телефона.

В репозитории нет ни кодов, ни ключа. Выдачей и отзывом кодов занимается ведущий разработчик.
